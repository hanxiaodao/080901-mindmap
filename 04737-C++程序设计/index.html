考点5函数重载与调用规则C2025.04、2023.10、2024.10、2026.04▼
5.1 核心规则
  • 重载 = 同名不同参（参数个数、类型、次序不同），返回值类型不参与重载。
  • 调用时按实参精确匹配决议：`fun(15.0)` 匹配 fun(double)、`fun(15)` 匹配 fun(int)（2025.04 分析36：5 + 30 = 35）。
  • 函数必须先定义或声明后调用：一个源文件中 f2() 可以调用定义在它之前的 main() 和 f1()（2024.10 填空21）。
  • 默认参数与重载同用可能产生二义性：如 `f(int)` 与 `f(int,int=5)`，调 f(1) 时编译器无法选择。
  • 函数定义 = 返回类型 + 函数名(形参表)，形参表写"类型 形参名"逗号隔开；调用写函数名加实参（2026.04 程序填空20：max(int a,int b) 与 max(x,y)）。

写法含义人话

6.4 常量定义（const 常量 vs #define 宏）

写法结果
`const double pi = 3.14;`✅ 正确
`const pi = 3.14;`❌ 缺类型（a type specifier is required）
`const double pi; pi = 3.14;`❌ const 变量必须定义时初始化
`double pi = 3.14;`⚠️ 语法对，但不满足"用常量定义"的要求
`#define PI 3.1415926`✅ 宏也可以，不能写 =、末尾不加分号

考点7引用与传参C2023.10、2024.04、2024.10、2025.10、2026.04▼
7.1 核心规则
  • 引用的本质是变量的别名，格式 `类型 &引用名 = 变量名;`。
  • 引用必须初始化，且不能用常量、表达式初始化非常量引用（`int &r = 5;` 错，`const int &r = 5;` 可以）。
  • 引用不能更换指向、不能为空——绑定后全程只指向同一变量（2026.04 单选2）。
  • 传值：形参是副本，改形参不动实参；传引用：形参是别名，改形参就是改实参（2024.10 分析36 的 setzero(int &a)）。
  • 读出函数要用引用把数据带出去：`void get(string &p, int &a, int &b)` 把对象内数据赋给外部变量——值传递只改副本，"读出"无效（2024.04 设计47 实际错点）。
  • 引用作函数返回值：函数返回的是原变量的别名，可作左值继续赋值。
  • 指针传参要传地址：对象 `v1` 要写 `&v1`，数组名 `v2` 本身就是地址（2023.10 单选3：f1(&v1,v2)）。

  • 三大互斥域：basefield（dec|oct|hex）、adjustfield（left|right|internal）、floatfield（scientific|fixed）。
  • 标志字是什么：每个流对象内部有一组格式开关位，`ios::xxx` 就是这些开关的常量名——`ios::dec` 十进制、`ios::oct` 八进制、`ios::hex` 十六进制、`ios::left/right` 对齐、`ios::scientific` 科学计数法……而 `ios::basefield` 不是开关，是「域掩码」：它等于 dec|oct|hex 三个开关的合并，用来一次性圈住整个进制域；同理 adjustfield 圈对齐域、floatfield 圈浮点域。
  • setf 两参数形式 `setf(新标志, 域掩码)` 的意思：先把域掩码圈住的旧开关全部清零，再打开新开关——保证同域互斥的标志只剩一个。`cout.setf(ios::dec, ios::basefield)` 读作「进制域清零后设为十进制」，`setf(ios::hex, ios::basefield)` 就是「清掉 dec/oct 残留、切到十六进制」（2023.10 单选17）。单参数 `setf(标志)` 只置 1 不清 0，同域旧标志还挂着，dec|hex 同置后进制不可靠——所以进制/对齐/浮点域切换必须用两参数形式。
  • 2023.04 分析45 首句 `cout.setf(ios::dec,ios::basefield)`：默认本来就是十进制，这句是「保险动作」，输出仍是 234，认识写法即可。
  • 常见标志字：skipws、dec/oct/hex、showbase、showpoint、uppercase、showpos、scientific、fixed、unitbuf。
  • setiosflags/resetiosflags 作用持久；setw/width 一次有效（教材表 7-6 口径）。
  • `setiosflags(ios::resetiosflags)` 是错误用法——resetiosflags 是独立操纵符不是标志字（2025.10 单选16）；教材习题答案中 `setiosflags(ios::hex)` 是合法用法。

高频易错▼
类定义结尾漏分号；构造函数写返回类型；析构函数带参数——三个"不可能"。 后置 ++ 重载必须加 int 形参区分；前置返回引用、后置返回值（修改前的副本）。 =new 出来的对象必须 delete；new[] 必须配 delete[]；基类指针 delete 派生对象必须虚析构。 setw/width 只对下一个输出有效；setprecision 默认是有效数字位数，加 fixed/scientific 后才是小数位。 class 默认 private 继承；派生类对象永远访问不了基类私有成员；派生类指针=基类地址必须强转。 复制构造形参必须是引用（值传递会无限递归）；静态成员类外定义不再写 static。 友元关系单向、不传递；静态成员函数没有 this，也不能声明为虚函数。 构造顺序：基类→成员对象→自身（析构相反）；虚基类只构造一次、由最远派生类负责。 operator double() 不写返回类型；强制类型转换运算符只能重载为成员函数。 标识符三不：不能数字开头（123abc）、不能是关键字（int）、不能含连字符等非字母数字下划线符号（abc-123）。

考前速记▼
  • 题型：2023–2025 口径 = 单选 20 + 填空 0~10 + 程序填空 20~30 + 程序分析 30 + 程序设计 20；2026.04 改版 = 单选 10×2 + 填空 5×2 + 程序填空 5 空×4 + 程序阅读 4×5 + 程序设计 2×15（是否延续【待核实】）。
  • 程序分析五坑位：顺序 / 静态 / 重载 / 虚绑定 / 格式；2026.04 改考基础追踪：指针解引用 / 构造析构 / 递归 / 虚绑定。
  • 标识符：字母/数字/下划线组成、不能数字开头、不能是关键字、区分大小写。
  • 引用：必须初始化、是别名、不能换绑定、不能为空。
  • 不可重载：`. .* :: sizeof ?: #`；只能成员重载：`= [] () ->`；默认已重载：`= &`。
  • 动态绑定两条件：virtual + 基类指针/引用。
  • 纯虚函数：`virtual 返回类型 函数名(参数)=0;` 抽象类不能实例化、可定义指针引用。
  • 后置 ++ 加 int 形参；流插入提取只能友元且返回流引用。
  • setw 一次有效；setprecision 默认有效位；fixed/scientific 后变小数位。
  • 互斥域：basefield / adjustfield / floatfield，切换前先清。
  • class 默认 private 继承；protected=外界不可、派生类可。
  • 构造顺序：基类→成员对象→自身；析构相反；虚基类一次。
  • 复制构造三时机：初始化对象、传值实参、返回对象。
  • 常对象只能调常成员函数；const 版本与非 const 版本构成重载。
  • 静态成员：类外定义不写 static；静态函数无 this。
  • 友元：单向、不传递、可访问私有。
  • cerr 非缓冲、clog 缓冲，都不能重定向。
  • 流状态：goodbit 0 / eofbit 1 / failbit 2 / badbit 4；Ctrl+Z 结束 cin。
  • 文件模式：in（不存在出错）/ out（清空）/ app（追加）/ binary；二进制写= out|binary。
  • 函数匹配顺序：普通函数 → 模板函数 → 转换后普通函数 → 报错。
  • 类模板实例化：模板类→对象，必须给类型实参。
  • 空类大小 1 字节；成员按最宽类型补齐。
