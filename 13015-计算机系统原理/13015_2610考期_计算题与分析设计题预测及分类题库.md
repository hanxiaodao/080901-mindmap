## 考点1 第1章 性能指标计算 【等级 A+ 必考，5/5 全考】

### 套路（万能三件套）

```
① 程序总时钟周期数 = Σ(各类指令条数ᵢ × CPIᵢ) = 总指令条数 × CPI
② 综合CPI = 总时钟周期数 ÷ 总指令条数 = Σ(CPIᵢ × 该类指令占比fᵢ)
③ 用户CPU时间(执行时间) = 总时钟周期数 ÷ 时钟频率 = 总时钟周期数 × 时钟周期
④ MIPS = 指令条数 ÷ (执行时间 × 10⁶) = 时钟频率 ÷ (CPI × 10⁶)
⑤ 峰值MIPS：选 CPI 最小的指令计算
⑥ 比较快慢：执行时间短者快；快多少 = 时间之比（或每条指令平均时间之差）
```

**三种典型变体：**
- **两序列/两机器比较型**：先分别算总周期数→CPI→执行时间→比较。注意"指令条数少的不一定快"。
- **优化替换型**（乘4→左移）：替换条数 = 时钟频率 × 节省的执行时间 ÷ (CPI乘 − CPI移)。
- **时间占比型**：CPU时间占比 = 用户CPU时间 ÷ 总时间。

### 真题
- 【24.04-27】4类指令 CPI=1,2,4,6；P1(4,2,2,1)条，P2(2,5,3,2)条。哪个指令少？哪个快？CPI？
  → P1：9条、22周期、CPI=22/9≈2.44；P2：12条、36周期、CPI=3.0。同机器比较总周期数，P1 快。
- 【24.10-27】四类指令占比 50/20/20/10，CPI=1,2,2,2；A类减少50%后求优化前后 CPI 和 MIPS（主频50MHz）。
  → 优化前 CPI=1.5、MIPS=50M/1.5≈33.3；优化后占比 33.3/26.7/26.7/13.3，CPI=1.67、MIPS≈29.9（结论：优化后 MIPS 反而下降，说明 MIPS 不可靠）。
- 【25.04-27 = 课后1-一-9 原题】4GHz，指令 8×10⁸，CPI=1.25 → 执行时间 = 8×10⁸×1.25÷(4×10⁹)=0.25s；总时间4s → 占比 0.25/4=6.25%。
- 【25.10-27】P1：M1(10⁸条,500ms)、M2(0.75×10⁸,250ms)；P2：M1(6×10⁵,6ms)、M2(8.4×10⁵,12ms)。
  → (1) P1 看 M2 快 1 倍（时间短）；(2) MIPS：M1上 P1=200、P2=100；M2上 P2=70，100/70≈1.43，M1 快 0.43 倍；(3) 频率400M/600M：CPI = 频率×时间÷条数 = 0.5×400M/100M=2、0.25×600M/75M=2。
- 【26.04-28 = 课后1-一-10 原题】S1：10条、19周期、CPI=1.9、38ns；S2：8条、26周期、CPI=3.25、52ns（500MHz）。

### 课后习题大题
- 【课后1-一-7】【课后2-一-7】M1/M2 五类指令，求峰值 MIPS（选最小CPI：1GHz/1×10⁶=1000；1.6G/(2×10⁶)=800）+ 等条数时平均 CPI（(1+2+2+3+4)/5=2.4；(2+2+4+5+6)/5=3.8）+ 执行时间比较（2.4N/1G vs 3.8N/1.6G）。
- 【课后1-一-8】【课后2-一-8】时钟周期 0.8ns/1.2ns、CPI 4/2：执行时间 3.2N vs 2.4N，M2 快 0.8ns/条。
- 【课后1-一-11】【课后2-一-11】400MHz，12.000s→11.008s，CPI 102→2：条数 = 400M×0.992÷(102−2) = 3.968×10⁶ 条。（注意课后2版本若为 12→10s，则 400M×2÷100=8×10⁶=800M 条）

## 考点2 第5章 Cache 计算与分析 【等级 A 必考级，4/5 分析题 + 26.04 计算题】

### 套路（五步法，一步都不能少）

```
设：主存空间 M、块大小 B、cache 数据区 C、路数 k（直接映射 k=1，全相联只有1组）
① 主存地址位数 = log₂M
② 块内地址位数 = log₂B（低字段）
③ 组号/行号位数：
   直接映射：行数=C/B，行号=log₂(行数)（中间字段）
   组相联：组数=C/B/k，组号=log₂(组数)（中间字段）
   全相联：无此字段（0位）
④ 标记位数 = ① − ② − ③（高字段）
⑤ cache 总容量 = 行数 × (数据位 B×8 + 标记 + 有效位1 + 修改位 + LRU位)
   修改位：回写(write back)=1位，通写(write through)=0位
   LRU位：k路组相联 = log₂k 位；直接映射/全相联无（全相联如给也按题目）
```

**命中率类（数组访问）：**
- 元素 4B（int），块大小 B → 每块元素数 = B/4；行优先存放+行优先访问 → 每块仅第一个元素缺失。
- 命中率 = (总访问数 − 缺失数)/总访问数。注意首地址是否对齐块边界：不对齐则第一块多缺失一次。
- 平均访存时间 = 命中时间 + (1−命中率) × 缺失损失。

**地址序列模拟类**（如 2,3,11,16,…）：
- 直接映射：行号 = 主存块号 mod 行数，画表逐个标 miss/hit；块含 w 个字时 块号=地址÷w。
- 全相联：任意空行装入，比较全部标记。

**访问过程标准话术**（直接映射）：把地址按"标记|行号|块内"切分 → 按行号定位行 → 有效位=1 且标记相等 → 命中，按块内地址取数；否则缺失，把该主存块调入该行，置有效位=1、写标记。（组相联：按组号定位组 → 组内逐行比较标记；全相联：全部行比较标记，装入任意行。）

### 真题
- 【24.04-30】直接映射，块64B，数据区2KB，主存256KB：18位 = 标记7 + 行号5 + 块内6；访问 0240CH：主存块144 → 映射第16行，cache空则缺失装入、置有效位1、标记=0000100。
- 【24.10-30】全相联，块64B，数据区1KB，主存256KB：18位 = 标记12 + 块内6；0240CH 的 12 位标记与各行比较，命中则取数，否则装入任意空行。
- 【25.04-30】512MB主存、16行、块128B、2路组相联、通写+LRU：(1) 29位主存地址 = 标记19 + 组号3 + 块内7；总容量 = (128×8 + 19 + 1 + 1)×16 = 16720位 = 2090B（解析件原文"16270位"系笔误，按公式应为16720位）；(2) int数组128×128按行访问：每块 128/4=32 个元素，首地址640=5×128 对齐 → 命中率 31/32 = 96.875%。
- 【26.04-27 = 课后1-五-14 原题】64MB主存、4KB数据区、4路组相联、LRU、回写、块64B：(1) 26位 = 标记16 + 组号4 + 块内6；(2) 总容量 = 64行×(16+1+1+2+64×8) = 34048位。

### 课后习题大题
- 【课后1-五-8】【解答-5-7】1GB主存、64KB数据区、直接映射、通写、块32B：30位 = 标记14 + 行号11 + 块内5；总容量 = 2048×(1+14+256) = 555008位。

## 考点3 第2章 IEEE754 浮点数表示与转换 【等级 B+，≈45%，从未考过大题、解析点名的轮换考点】

### 套路（十进制→IEEE754 单精度 六步）

```
① 十进制 → 二进制（整数除2取余；小数乘2取整）
② 二进制规格化：±1.F × 2ⁿ
③ 符号位 s（1位）：正0负1
④ 阶码 e（8位）= n + 127，转 8 位二进制（偏置常数127；双精度为11位、偏置1023）
⑤ 尾数 f（23位）= F 后面补0补满（隐藏位1不存）
⑥ 排列 s | e | f → 四位一组 → 十六进制
反向（16进制→十进制）：拆 s/e/f → n = e十进制 − 127 → 值 = (−1)ˢ × (1.F)₂ × 2ⁿ → 按权展开
特殊值：阶码全0=非规格化数（×2⁻¹²⁶，隐藏位为0）；阶码全1=±∞/NaN
```

### 课后习题大题
- 【课后1-二】67.375 → 1000011.011 = 1.000011011×2⁶ → 0|10000101|00001101100…0 = **4286 C000H**。
- 【课后1-二】41A50000H → 0|10000011|0100101…0 → 1.0100101×2⁴ = 10100.101₂ = **20.625**。
- 【课后1-二-12】【解答-2-9】4098：补码 00001002H；IEEE754 = 0|(12+127=139)|00000000010…0 = **4480 1000H**；两种表示中相同的序列是"00000000010"（因规格化后首个1被隐藏）。
- 【解答-2-10】−2147483647：补码 80000001H（精确）；IEEE754 = 1 10011110 111…1 = CEFF FFFFH（近似，尾数只有24位有效）。
- 【解答-2-8 / 课后2-二-11】+1.625=3FD00000H、−9/16=BF100000H、+1.75=3FC00000H、+19=41 980000H、−1/8=BF000000H、258=43810000H（自己验算一遍）。
- 【解答-2-18】IEEE754 加减四步：**对阶（小阶向大阶看齐，尾数右移）→ 尾数加/减 → 规格化（左规/右规）→ 舍入**（+溢出判断）。例：0.75+(−65.25) = −64.5。
- 【解答-2-11】大小端存放：x=−0.125→BE000000H、y=7.5→40F00000H、i=100→0064H，大端低位字节在高地址，小端相反。

## 考点4 第3章 机器级指令分析 【等级 B+，≈45%（24.04~25.04 三连考，已休2期）】

### 套路

**① Intel → AT&T 转换规则：**
```
· 目的/源操作数位置互换（Intel: mov dst,src → AT&T: mov src,dst）
· 寄存器加 %，立即数加 $
· 长度后缀：BYTE→b、WORD→w、DWORD→l（由寄存器名或 PTR 决定）
· 内存操作数：DWORD PTR [ebp+20] → 20(%ebp)
  [ecx+edx*2+4] → 4(%ecx,%edx,2)   格式：偏移(基址,变址,比例因子)
```
【24.04-29 全解】push ebp→pushl %ebp；mov edx,[esp+8]→movl 8(%esp),%edx；mov al,255→movb $255,%al；mov WORD PTR [ebp+20],cx→movw %cx,20(%ebp)；lea eax,[ecx+edx*2+4]→leal 4(%ecx,%edx,2),%eax。

**② leal 的算术用法**：【课后1-三-7】D(Rb,Ri,S) → R[edx] = R[Rb] + R[Ri]×S + D：leal (%eax),%edx → x；4(%eax,%ecx) → x+y+4；(%eax,%ecx,8) → x+8y；0xc(%ecx,%eax,2) → y+2x+12。

**③ 标志位规则（加减）：**
```
无符号：CF = Cout（加）；CF = Cout⊕1（减，借位）；CF=1 ⇒ 无符号溢出
带符号：OF = 最高位进位 ⊕ 次高位进位 = (两加数同号而结果异号)；OF=1 ⇒ 补码溢出
SF = 结果最高位；ZF = 结果全0时为1
加法器最高位进位 Cout：无符号加法 CF=Cout；减法 CF=Cout取反
带符号数比较大小不能用 CF（用 SF⊕OF）
```
- 【24.10-29】add ax,bx：FFFAH+FFFOH=FFEAH；CF=1（无符号 65530+65520=131050>65535 溢出）、OF=0（带符号 −6+(−16)=−22 正确）、SF=1、ZF=0。
- 【25.04-29】mulb %cl：R[ax]←R[al]×R[cl]，A0H×03H：160×3=480=01E0H，高8位非全0 → CF=OF=1；imulb %cl：−96×3=−288=FEE0H，高9位不全0/1 → CF=OF=1。
- 【课后2-二-16 / 解答-2-13,14】8位补码 x=−68,y=−80 加/减后的 OF/SF/ZF/Cout 全套计算（加：6CH，OF=1 溢出；减：0CH，OF=0 正确）。
- 【解答-2-15】补码加减部件表格题：对 X+Y、X−Y 分别填 x+y、OF、SF、CF 并解释。

**④ 类型扩展/截断**：【课后1-三-5】【解答-3-5】char→int 用 movsbl（符号扩展）、unsigned char→unsigned 用 movzbl（零扩展）、int→char 截断 movb；规律：**小→大：无符号零扩展、有符号符号扩展；大→小：直接截断低位**。【解答-2-12】65535 截断为 short 再扩展 → −1。

**⑤ C↔汇编互译**：【课后2-三-9】v = (z<<8) + x*k − (y & 0xFF00)（sall/imull/andl/addl/subl 组合）；【课后2-三-6】由 mov 序列还原三指针轮换函数。

## 考点5 第5章 主存扩展（DRAM 芯片 / ROM-RAM） 【等级 B，≈40%（24.04、24.10 后已4期未考）】

### 套路

```
① 所需芯片数 = 总容量 ÷ 芯片容量（注意位扩展：16K×4位 → 8位需 2片并联一组）
   一般式：组数(字扩)×每组片数(位扩)
② 内存条数 = 主存容量 ÷ 单条容量
③ 地址划分：芯片内地址位数 = log₂(芯片单元数)；选片位数 = log₂(芯片组数)
④ ROM/RAM 地址范围：ROM 占低地址区，RAM 紧随其后到最高地址；
   区分位 = 两区交界处对应的最高变化位（如 0000~7FFFH 与 8000~FFFFH 由 A15 区分）
```

### 真题
- 【24.04-28 = 解答-5-1 原题】4GB 空间，64M×8位芯片组成 512MB、64位内存条：(1) 512MB/(64M×8b)=**8片**；(2) 2GB/512MB=**4条**；(3) 32位地址，A25~A0 为芯片内地址，A28~A26 选芯片。
- 【24.10-28 = 解答-5-3 原题】64KB 空间，ROM 0000H~7FFFH，用16K×4位芯片构成 32K×8 位 RAM：(1) RAM 区 **8000H~FFFFH**，芯片数 = 32K×8/(16K×4)=**4片**，**A15** 区分 ROM/RAM；(2) 地址线改24位：(2²⁴−2¹⁵)/(16K/2)= (16M−32K)/32K×2 → **2044片**。
- 【解答-5-2】DRAM 引脚数：256K×1→9根地址/1位数据；16M×8→12/8；32M×4→13/4（行列地址分开复用，r≤c 且 |r−c| 最小）。

## 考点6 第5章 虚拟存储器（页表 / TLB） 【等级 B-，≈30%（25.10 刚考过一次）】

### 套路

```
① 页内偏移位数 = log₂(页大小)
② 虚页号位数 = 逻辑地址位数 − 偏移位数；实页号（物理页框号）位数 = 物理地址位数 − 偏移位数
③ 页表项数 = 2^虚页号位数
④ 页表项位数 ≥ 实页号位数 + 有效位 + 修改位 + 使用位 + 存取方式位（按题给）
⑤ 页表大小 = 页表项数 × 页表项位数 ÷ 8 → 字节
⑥ TLB：组数=表项数/路数；组号位数=log₂(组数)（取虚页号低位）；TLB标记=虚页号位数−组号位数；
   TLB 每项位数 = 页表项位数 + 标记位数；TLB大小 = 表项数 × 每项位数
⑦ 虚→实转换：虚页号查页表/TLB 得实页号，拼接页内偏移
```

### 真题
- 【25.10-30】逻辑40位、物理32位、页16KB：偏移14位，虚页号26位、实页号18位；页表项 2²⁶ 个，每项 1+1+2+2+18=24 位 → 页表 = 2²⁶×24b = **192MB**。

### 课后习题大题
- 【解答-5-17】虚40/物36位、页16KB、控制位共4位：页表项 26位（取32位），页表 = 2²⁶×32b = **256MB**（问题：页表远大于一页，无法一次装入内存）。
- 【解答-5-18】逻辑36/物理32位、页16KB：页表 ≥ 24×2²² b = **12MB**；TLB 256项、2路组相联 → 128组，组号7位、标记15位，每项 24+15=39位 → TLB = 256×39 = **9984位 = 1248字节**。
- 【解答-5-19】TLB+L1 cache 综合大题：16位虚地址/12位物理地址/页128B；虚页号9位=TLB标记7+组索引2；物理地址=标记6+行索引4+块内2；完整走一遍 067AH 的 TLB→页表→cache 三级查找（★此类综合题是最难变体，值得完整做一遍）。

## 考点7 第2章 补码/无符号加减运算与标志位 【等级 C+，≈25%（25.10 计算题刚考过）】

### 套路（标准答题模板）

```
① 写出补码：x=75→0100 1011B→4BH（负数：|x|取反加1）
② 按位相加（减法：x+[−y]补），超出字长的进位丢弃，得结果寄存器内容（16进制）
③ 判断结果是否正确：无符号看是否在 0~2ⁿ−1 内；带符号看是否在 −2ⁿ⁻¹~2ⁿ⁻¹−1 内
④ Cout = 最高位进位；加法：CF=Cout；减法：CF=Cout⊕1（借位）
⑤ 带符号：OF = 最高位进位⊕次高位进位；SF=结果符号位；ZF=结果为0置1
⑥ 用真值验证：无符号溢出时真值=结果+2ⁿ（有进位）；补码真值按补码规则还原
```

### 真题与课后习题

- 【解答-2-14】带符号 −68+(−80)：BCH+B0H=(1)6CH → 6CH=+108 错误（真值 −148 < −128 溢出），Cout=1、OF=1、SF=0、ZF=0；−68−(−80)=0CH 正确，OF=0。
- 【解答-2-16】无符号/带符号乘法截断对比表（3位×3位截断，理解截断丢高位即可）。

## 考点8 第6章 I/O：中断 / DMA 主机占用率 【等级 C，≈15%（26.04 刚考过）】

### 套路

```
① 每秒中断次数 = (磁盘传输速率 ÷ 每次传送数据量) × 磁盘工作时间占比
② 每秒I/O开销（周期）= 每秒中断次数 × 每次中断开销周期
③ 主机占用率 = I/O开销周期 ÷ (主频 × 10⁶) × 100%
DMA 方式：整块传输完才中断一次 → 次数 = 传输速率×占比 ÷ 块大小，占用率骤降
```

### 真题
- 【26.04-29】500MHz、16B 缓冲器、4MB/s、每次中断 500 周期、磁盘仅 5% 时间传送：
  满速每秒中断 4M/16=262144 次 → 实际 262144×5%≈13107 次/s → 开销 13107×500≈6.55M 周期/s → 占用率 ≈ 6.55M/500M ≈ **1.31%**（若按 4×10⁶ 计算则 12500×500/500M=1.25%；答题给过程和量级即可）。
- 对比记忆：若改用 DMA（如每次传 4KB，整块结束中断一次），占用率会缩小数百倍——这是常见追问点。

## 考点9 第6章 总线带宽（FSB / QPI / 存储器总线 / PCI-e） 【等级 C，≈15%（25.04 刚考过，均为课后原题）】

### 套路（四大公式，直接套）

```
FSB：工作频率 = 时钟频率 × 倍频(如4倍并发)；带宽 = 工作频率 × (总线宽度/8) [B/s]
```

## 考点10 第1章 流水线性能分析 【等级 C，≈15%（25.10 考过）】

### 套路

```
流水线执行速度取决于"最慢流水段"（瓶颈段）：
· 缩短非瓶颈段 → 不能加快（瓶颈仍是它）
· 延长某段但 ≤ 瓶颈段时间 → 无影响
· 延长超过瓶颈段 → 新瓶颈，时钟周期=新最长时间，速度下降
· N 条指令、k 段、周期 τ：总时间 = (k + N − 1)×τ；加速比 ≈ k（理想）
```
