考点12命题逻辑推理 (补充内容)▼
12.1 直接证明法 常用规则：
分离规则（P→Q且P，可得Q）：若前提包含 P 和 P→Q，则可推出 Q。 析取三段论（P∨Q且¬P，可得Q）：若前提包含 P∨Q 和 ¬P，则可推出 Q。 合取消去（P∧Q可得P，也可得Q）：若前提包含 P∧Q，则可单独推出 P 或 Q。 双条件分解（P↔Q可得P→Q，也可得Q→P）。 注意：题目给出条件 P，表示 P 为真；给出条件 ¬P，表示 P 为假。 12.2 归谬法（反证法） 思路：要证明结论 Q 为真，先假设结论 Q 为假（即假设 ¬Q 为真），然后将 ¬Q 加入前提集合，进行推理。如果最终推出矛盾（如 P ∧ ¬P），则说明假设 ¬Q 不成立，故原结论 Q 必为真。 使用场景：
题目明确要求用归谬法。
结论不好直接证明时。
12.3 推理规则与示例 推理的符号表示：
前提1，前提2，... ⊢ 结论
例如：{P→Q, P} ⊢ Q 表示前提集合 {P→Q, P} 可以推出结论 Q。 使用推理规则解题步骤：
写出所有前提和结论。
按编号列出推理步骤，每一步写出当前得到的命题。
在每一步后注明该步由第几步以及使用了什么规则得出。
示例：{P∧Q, Q→¬R, R∨S} ⊢ S (1) P∧Q (前提) (2) Q (由(1)，合取消去)
(3) Q→¬R (前提) (4) ¬R (由(2), (3)，分离规则) (5) R∨S (前提) (6) S (由(4), (5)，析取三段论)

2.4 求解方法：真值表法（优先） 列出真值表：列出所有命题变项的真值指派（从全1到全0）。

析取连接：将这些小项用析取符号（∨）连接，即得主析取范式。 原理：命题公式的主析取范式就是所有使其为真的赋值对应小项的析取。
2.5 求解方法：等值演算法（次选） 化简形式：通过等值演算，将公式化为析取范式形式。
补全小项：对于每个析取项（合取式），通过“添项”技巧，使用 A∧(B∨¬B) ≡ A 将缺失的变项补全，使其变成小项。 整理结果：利用幂等律 A∨A≡A 去掉重复项，并按小项的二进制表示排序。 技巧：如果题目明确要求用等值演算但推不出来，可以用真值表法得出答案，再反向书写简单的演算过程。

5.1 核心性质总结 任意不同小项的合取为假 (F)：mᵢ ∧ mⱼ ≡ F (i ≠ j) 任意不同大项的析取为真 (T)：Mᵢ ∨ Mⱼ ≡ T (i ≠ j) 大项的否定是小项，小项的否定是大项：¬Mᵢ ≡ mᵢ， ¬mᵢ ≡ Mᵢ 5.2 性质证明与举例 证明“任意不同小项的合取为假”：

任取一个大项，例如 M₂ = ¬p∨q。 ¬M₂ = ¬(¬p∨q) = p ∧ ¬q。这正是小项 m₂（对应指派 p=1, q=0）。 练习（选不正确项） "任意两个不同小项的析取必为重言式"——不正确：m₁∨m₂=(¬p∧q)∨(p∧¬q)，在 00、11 行均为假 对照记牢：任一赋值恰使一个小项为真；mᵢ ⇔ ¬Mᵢ；全部小项的析取=永真式；全部大项的合取=永假式

考点7自然推理规则（CP规则）▼
利用等值式或蕴含式得出结论，然后将该结论作为前提，继续执行上述步骤，直到得出所求结论，推理得证。主要规则：1. P规则（前提引入规则）任何前提都可直接作为结论，即“H⇒H”。2. T规则（置换规则）之前已得出的结论可以通过等值式或蕴含式转为另一个结论。3. CP规则
CP规则（附加前提）当要证明的结论是蕴涵式（如 A → B）时，将前件 A 作为附加前提引入，然后推出后件 B，即可证明 A → B 成立。 4. 归谬法要证明一个结论 C 是一组前提 H₁, H₂, ..., Hn 的有效结论，可以假设结论 C 为假（即 ¬C 为真），并将这个假设作为一个附加前提加入到原有的前提集合中。如果从这个扩大的前提集合中，最终能推出一个矛盾（如 P ∧ ¬P 或 F），则说明假设 ¬C 不成立，从而证明原来的结论 C 为真，推理有效。 四大基本推理规则
名称形式说明
假言推理（分离）p→q，p ⊢ q肯定前件
析取三段论p∨q，¬p ⊢ q否定一个取另一个
合取消去p∧q ⊢ p（及 q）合取式可拆
双条件推理p↔q，p ⊢ q；p↔q，¬p ⊢ ¬q同真同假

考点29.2 哈密顿回路▼
定义：
从某个节点出发，经过每个节点有且仅一次，最后回到该节点
与欧拉回路的区别：欧拉回路要求每条边都走，哈密顿回路只要求每个点都经过
判断方法： 没有严格的判断方法，只能尝试走一遍。
常见非哈密顿图的图形（记住即可）：
有一个经常考的特定图形，记住它不是哈密顿图。
狄拉克定理（Dirac's Theorem）
在一个具有 n 个顶点的简单无向图中（n≥3），如果每个顶点的度数都至少为 n/2，那么该图中一定存在一条哈密顿回路
真题示范（25年10月·证明题35）： 30 人参加会议，每人至少有 15 个朋友，证明：可围圆桌入座使相邻的人都是朋友。
①建模：人→结点，朋友关系→连边，得简单图 G，n=30；②验证条件：n=30≥3，每人≥15 个朋友 ⇒ 每个顶点度数 ≥15=n/2；③引用狄拉克定理 ⇒ G 存在哈密顿回路，按回路顺序入座，相邻（含最后一人与第一人）都是朋友 ∎
信号词：「每人至少 n/2 个朋友」＋「围成圆桌相邻都认识」→ 套狄拉克定理。它是现成定理，证明题里直接引用，不用现场证明
注意：狄拉克定理只是充分条件——度数不足 n/2 仍可能有哈密顿回路：五边形 C₅ 每点度数 2 < 2.5，但它本身就是一个哈密顿回路。对照记忆：欧拉图有充要条件（连通＋全偶度数），哈密顿图没有好用的充要条件，「证明存在」就引用狄拉克定理，「证明不存在」用构造或反证

设 3 度结点有 n−9 个，总度数 = 8×1 + 1×4 + (n−9)×3 = 3n−15
树的握手定理：3n−15 = 2(n−1) → n = 13
例3：已知各度结点数，求未知结点数 例题： 树中 1 度结点 40 个、2 度结点 20 个、3 度结点 31 个，无 6 度及以上结点，求 4 度、5 度结点各几个。
设 4 度 x 个、5 度 y 个：总度数 = 40×1+20×2+31×3+4x+5y = 173+4x+5y；总结点数 = 91+x+y
握手定理：173+4x+5y = 2(91+x+y−1) → 2x+3y = 7
非负整数解只有 x=2、y=1（x=0、1、3 时 y 都不是整数）→ 4 度结点 2 个，5 度结点 1 个
考点79.7 克鲁斯卡尔算法▼
用于求最小生成树：
权值： 边上的数值，理解成代价（车费、距离、造价）；带权图： 每条边都带权值的图
最小生成树： 连接全部 n 个结点的 n−1 条边中，总权值最小的一棵树
步骤：
将所有节点保留，边全部去掉
从权值最小的边开始连接
如果连接后没有形成圈，则保留该边
如果形成圈，则舍弃该边
重复步骤2-4，直到选够 n−1 条边（n 为节点数）
例题演示：
6个节点的带权图，用克鲁斯卡尔算法求最小生成树。
步骤：
权值为1的边 → 保留（未形成圈） 权值为2的边 → 保留（未形成圈） 权值为3的边 → 舍弃（形成圈） 继续选择…
选够5条边（6−1=5）时停止
本图选中的 5 条边权值为 1、2、4、5、6 → 总权值 = 1+2+4+5+6 = 18 应用：题目不明说算法（真题） 识别特征： 工厂、村庄、城市、车站当点，道路/线路当边，距离/造价当权值，求“连通所有点的最小代价” → 最小生成树问题，套克鲁斯卡尔
例（最短供电线路）： 5 个工厂 A~E，两两架线距离 AB=16、AC=7、AD=5、AE=6、BC=6、BD=9、BE=8、CD=13、CE=11、DE=4，求连通 5 厂的最短线路总长。
权值升序选边：DE 4 ✓ → AD 5 ✓ → BC 6 ✓（AE 6 会与 AD、DE 成圈，弃）→ AC 7 ✓　已选 4 条 = 5−1，停 最短线路总长 = 4+5+6+7 = 22

考点99.9 二叉树的遍历▼
三种遍历方式：
遍历方式顺序别名
先序遍历根 → 左 → 右先根
中序遍历左 → 根 → 右中根
后序遍历左 → 右 → 根后根
例题： 对下面的二叉树做三种遍历——A 是根，B、C 是 A 的左右孩子，D、E 是 B 的左右孩子，F、G 是 E 的左右孩子：
先序（根左右）： A B D E F G C　// 根 A → 整个左子树（B、D、E、F、G）→ 右孩子 C；子树内递归同规则
中序（左根右）： D B F E G A C　// 最左的 D 先出，左子树全部走完才轮到根 A
后序（左右根）： D F G E B C A　// 根 A 排在最后
方法总结： 根的位置固定——先序第一个、后序最后一个、中序把左右子树的序列隔开；先定位根，再对左右子树递归
考点109.10 算术表达式与二叉树▼
方法：
给定算术表达式，如何转换为二叉树：
找到最后运算的符号 → 作为根节点 该符号左边的部分 → 作为左子树 该符号右边的部分 → 作为右子树 递归进行
示例： 1+2−3
最后运算是减号 → 减号作根 左边 1+2 → 加号作左子树的根 右边 3 → 直接作为右子叶 三种遍历结果：
对于表达式 (3×B)÷(C−D)：
先序： ÷×3B−CD 中序： 3×B÷C−D 后序： 3B×CD−÷
三个提速技巧：
① 中序 = 直接去括号抄原式——只有先序、后序才需要重排
② 表达式遍历中数字的相对顺序永远不变（本例是 3、B、C、D），挪的只是运算符位置：先序符号在最前、中序居中、后序在最后
③ 动手前先按运算顺序补上隐含括号：1+2−3 实为 (1+2)−3，最后运算的 − 才是根
再练一题： 写出 (a+3×b)÷(c−d) 的三种遍历：
最后运算 ÷ 作根 → 左子树 a+3×b（+ 作根，其右子树 3×b）→ 右子树 c−d 先序：÷+a×3b−cd　　中序：a+3×b÷c−d　　后序：a3b×+cd−÷
考点119.11 树的结点数公式（速算）▼
干嘛用的： 不画树、不枚举，直接用公式算出叶结点 / 分支点个数——填空题秒杀
11.1 任意二叉树：叶 = 二分支点 + 1 n₀ = n₂ + 1　// n₀ 叶结点数，n₂ 有 2 个孩子的结点数 证明： 设 n₁ 为恰有 1 个孩子的结点数。树中边数 = 孩子数总和 = 0·n₀+1·n₁+2·n₂（每条边恰是某个结点的一条孩子边，不除 2）；又 边数 = 总结点数 − 1 = n₀+n₁+n₂−1。两式相等化简得 n₀ = n₂+1 ✓
11.2 完全 m 叉树（每个分支点恰有 m 个孩子） 叶结点数 l = (m−1)·i + 1　　总结点数 n = m·i + 1　// i 为分支点数 由 m·i = n−1 = (i+l)−1 移项即得；考点8 例题"7 叶 → 6 分支"即此式（m=2 时 l = i+1）
11.3 正则 m 叉树（本笔记用法：叶都在同一层） 高 h（根在第 1 层）时：叶结点数 = m^(h−1)　// 例：高 5 正则三叉树 → 3⁴ = 81 术语提醒： 各教材叫法不同——有的教材把"每分支点恰 m 个孩子"叫正则 m 叉树、"叶同层"叫完全正则；做题认结构描述，别背名字
