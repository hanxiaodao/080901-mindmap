### 考点1：C++ 语言概述

meta: level=B; freq=2023.04、2023.10、2024.04、2024.10、2025.04、2025.10

#### 1.1 必背

- C++ 是**高级程序设计语言**，由 C 语言发展而来，**兼容 C**。
- 相对 C 最根本的变化：**引进类和对象的概念**（2023.04 单选1）。
- 支持面向对象、泛型编程、结构化（过程化）编程，三种范式都支持。
- 可跨平台运行（2025.04 单选1 选"可运行于 MAC"）。
- 代码复用粒度：**类 > 函数 > 变量**（2023.04 单选3）。
- 程序设计风格首要是**清晰、可读性好**（2024.04 单选1）。
- C++ 程序结构：**有且仅有一个 main 函数**；两种注释（`//` 行注释、`/* */` 块注释）。

#### 1.2 易错点

```err
"完全支持面向对象、不兼容C" "不支持泛型" "不支持过程化" 都是错误说法——C++ 三种编程范式全支持。
```

### 考点2：面向对象基本概念与类间关系

meta: level=B; freq=2023.04、2024.04、2024.10、2025.04、2025.10

#### 2.1 必背

- 面向对象的基本特点：**抽象、封装、继承、多态**（选项里"实例"不是特点，2025.10 单选3）。
- 抽象：把同一类事物的共同特点概括出来的过程（2024.10 单选3）。
- 对象 = **状态 + 行为**（人话：数据成员是状态，成员函数是行为）。
- 属性是描述对象的**静态特征**的数据项，操作（函数）是行为（2025.04 填空21）。
- 封装：把数据和操作（函数）捆在一起作为不可分割的整体处理（2024.04 填空24）。
- 对象结构图三要素：**类名、属性、操作**（不含"对象名"，2025.04 单选4）。
- 类间关系：**is-a（继承）、has-a（组合/包含）**。is-a 具有**传递性**（A→B→C，C 同时是 A 的成员，2024.04 填空29）。
- 结构化程序设计（面向过程）：**自顶向下、以函数为单位**，数据与操作分离；局限是大程序数据不安全、难维护——面向对象用类把数据与操作封装在一起（大纲识记层次，对比记）。

#### 2.2 怎么判断

- "学生是一种人" → is-a → 继承。
- "汽车有发动机" → has-a → 成员对象（封闭类）。

#### 2.3 真题

### 考点5：函数重载与调用规则

meta: level=C; freq=2025.04、2023.10、2024.10、2026.04

#### 5.1 核心规则

- 重载 = **同名不同参**（参数个数、类型、次序不同），**返回值类型不参与重载**。
- 调用时按实参**精确匹配**决议：`fun(15.0)` 匹配 fun(double)、`fun(15)` 匹配 fun(int)（2025.04 分析36：5 + 30 = 35）。
- 函数必须**先定义或声明后调用**：一个源文件中 f2() 可以调用定义在它之前的 main() 和 f1()（2024.10 填空21）。
- 默认参数与重载同用可能产生**二义性**：如 `f(int)` 与 `f(int,int=5)`，调 f(1) 时编译器无法选择。
- 函数定义 = **返回类型 + 函数名(形参表)**，形参表写"类型 形参名"逗号隔开；调用写函数名加实参（2026.04 程序填空20：max(int a,int b) 与 max(x,y)）。

#### 5.2 真题

2026.04 程序填空20：补 max 形参表 int a,int b 与调用 max(x,y)（每空 4 分）
2025.04 分析36：a.fun(15.0)+a.fun(15) 输出 35（6 分）
2024.10 填空21：f2() 中可调用 main() 和 f1()

### 考点6：const、常量与指针

meta: level=B; freq=2023.10、2024.04、2024.10、2025.04、2025.10

#### 6.1 必背

| 写法 | 含义 | 人话 |
|---|---|---|
| `const int *p` | 指向常量的指针 | *p 不能改，p 能改 |
| `int * const p` | 常指针 | p 不能改，*p 能改 |
| `const int * const p` | 都不能改 | 全禁（2025.04 单选3 选"均禁止修改"） |

```tip
【记忆】const 在 * 左边管内容（*p），在 * 右边管指针本身（p）。
```

- 用 const 修饰的是**指向常量的指针**时，写法是在非常量指针声明前加 const（2024.10 填空25 相关）。
- `const_cast` 只能去掉**指针或引用**的 const 属性，不能去掉 const 变量本身的常量性。

#### 6.2 易错点

```err
const int *p = &a; 后 a 的值仍可以通过 a 自己修改，p 只是"不能通过 p 改"。2024.10 分析36：setzero(a) 改的是 a，*p 跟着变（1 2 1 → 0 0 0）。
```

#### 6.3 真题

2025.04 第3题：const char *const p 两个都禁止修改
2024.10 分析36：const 指针 + 引用传参输出 1 2 1 / 0 0 0
2024.04 第2题：const int *a=&a; 是不正确的 const 用法

#### 6.4 常量定义（const 常量 vs #define 宏）

- 格式：`const 类型名 常量名 = 初值;`，如 `const double PI = 3.1415926;`——**必须在定义处初始化**，此后只读。

| 写法 | 结果 |
|---|---|
| `const double pi = 3.14;` | ✅ 正确 |
| `const pi = 3.14;` | ❌ 缺类型（a type specifier is required） |
| `const double pi; pi = 3.14;` | ❌ const 变量必须定义时初始化 |
| `double pi = 3.14;` | ⚠️ 语法对，但不满足"用常量定义"的要求 |
| `#define PI 3.1415926` | ✅ 宏也可以，**不能写 =、末尾不加分号** |
| `#define PI = 3.14` / `#define PI 3.14;` | ❌ 多写 = 或多写分号，展开后编译报错 |

```err
const 常量 = 有类型的只读变量（编译期检查、遵守作用域）；#define 宏 = 预处理阶段的纯文本替换（无类型、无作用域、吃分号）。考试写「pi 用常量定义」两种都算，用 const 更稳。
```

#### 6.5 真题

### 考点7：引用与传参

meta: level=C; freq=2023.10、2024.04、2024.10、2025.10、2026.04

#### 7.1 核心规则

- 引用的本质是变量的**别名**，格式 `类型 &引用名 = 变量名;`。
- 引用**必须初始化**，且不能用常量、表达式初始化非常量引用（`int &r = 5;` 错，`const int &r = 5;` 可以）。
- 引用**不能更换指向**、**不能为空**——绑定后全程只指向同一变量（2026.04 单选2）。
- **传值**：形参是副本，改形参不动实参；**传引用**：形参是别名，改形参就是改实参（2024.10 分析36 的 setzero(int &a)）。
- **读出函数要用引用把数据带出去**：`void get(string &p, int &a, int &b)` 把对象内数据赋给外部变量——值传递只改副本，"读出"无效（2024.04 设计47 实际错点）。
- 引用作函数返回值：函数返回的是原变量的别名，可作**左值**继续赋值。
- 指针传参要传地址：对象 `v1` 要写 `&v1`，数组名 `v2` 本身就是地址（2023.10 单选3：f1(&v1,v2)）。

### 考点9：new/delete 与动态内存

meta: level=A; freq=2023.04、2024.04、2024.10、2025.04、2025.10、2026.04

#### 9.1 核心规则

- new 在**程序运行期间**分配内存，变量具有**动态生存期**（2024.10 单选2、2023.04 单选6）。
- new 的变量/对象直到 **delete**（或程序结束）生存期才结束（2024.10 填空25）。
- new 对象**加括号才初始化**（`new int(10)` 初值 10，`new int` 值随机）。

#### 9.2 必背（四种使用形式）

```f
int *p1 = new int(5);        // 分配变量并初始化
int *p2 = new int[10];       // 分配数组（不初始化）
A *p3 = new A;               // 分配对象（调默认构造）
A *p4 = new A[3];            // 分配对象数组（每个元素都调构造）
delete p1;                   // 释放变量/对象
delete[] p2;                 // 释放数组必须加 []
```

- **delete[] 与 new[] 配对**，忘写 `[]` 数组不能完全释放。
- 对象数组元素必须有无参（或全默认参数）构造函数。

#### 9.3 必背（对象数组的构造析构）

- `Demo *pd = new Demo[2];` 按下标**顺序**调构造；`delete[] pd;` **逆序**调析构（2023.04 分析42：1constructor 2constructor … 2destructor 1destructor）。

### 考点11：作用域与可见性

meta: level=B; freq=2023.04、2025.10

#### 11.1 必背

- 作用域从大到小：**命名空间（文件）> 类 > 局部（块）> 函数原型**（函数原型作用域最小，2023.04 填空22 考最大=命名空间）。
- **可见性（内层优先）**：内层同名标识符**屏蔽**外层——局部变量遮住全局变量、成员变量遮住形参。
- 被屏蔽的外层变量仍有生存期，只是不可见；成员变量被形参遮蔽时用 `this->` 或 `类名::` 访问。

### 考点12：变量的生存期与存储类别

meta: level=B; freq=2024.10、2025.04、2025.10、2025.04

#### 12.1 必背

### 考点21：复制构造函数与深浅拷贝

meta: level=A; freq=2023.04、2023.10、2024.10、2025.04

#### 21.1 是什么

- 格式**固定**：`A(const A &a)` —— 形参必须是**本类对象的引用**（写成值传递会无限递归）。
- **自动调用的三种情况**：① 用对象初始化新对象 `A b(a);` ② 对象作**实参传值** ③ 函数**返回对象**。

#### 21.2 核心规则（深浅拷贝）

| | 浅拷贝 | 深拷贝 |
|---|---|---|
| 指针成员 | 复制**地址**，两对象共享一块内存 | **new 新内存**再复制内容 |
| 后果 | 重复释放、非法访问（2023.04 单选8） | 安全，各管各的 |

```f
pointer(const pointer &t) {
```

### 考点25：友元

meta: level=S; freq=2023.04、2023.10、2024.04、2024.10、2025.04、2025.10、2026.04

#### 25.1 必背

```f
friend void Print(Date &d);        // 友元函数（写在类内任意位置）
friend class Line;                 // 友元类
```

- 友元**不是成员函数**，但能访问类的**所有成员**（不受访问权限限制）。
- 友元关系**单向且不传递**：A 是 B 的友元、B 是 C 的友元 ⇒ A 不是 C 的友元（2025.04 单选9）。
- 代价是破坏封装，收益是**提高访问效率**（2023.04 填空24）。
- 友元函数**没有 this 指针**；友元不是成员函数，不能被继承。

#### 25.2 怎么判断（固定大题模型：友元访问私有）

- 友元函数形参是对象引用，函数体内直接 `d.year` 访问私有成员（2023.04 程序填空38：补 friend void Print(Date&)）。
- 类 A 的成员函数要访问类 B 私有成员：在 B 中声明 `friend class A;`（2023.10 程序填空37：Line 访问 Point 私有 x,y）。
- 判空技巧：空长成 `____(const 类名& obj);` 且类外有同名函数定义、函数体访问 obj.私有成员 ⇒ 填 `friend void 函数名`，friend 不能丢；只填 `void Print(...)` 是声明了一个私有成员函数，类外定义照样报 private（2024.10 填空32：INTEGER 类补 friend void Print，另一空 this->a=a）。

#### 25.3 真题

## 第四章 运算符重载

### 考点26：运算符重载规则

meta: level=S; freq=2023.04~2026.04 全部 7 套

#### 26.1 必背（五条铁律）

- 实质：编写名为 `operator 运算符` 的函数（2024.04 填空27：operator delete）。
- **不能重载**：`.  .*  ::  sizeof  ?:  #`（2025.04 单选10 选 #）。
- 不能改变优先级、结合性、操作数个数，**不能创造新运算符**。
- `=  []  ()  ->` **只能重载为成员函数**（2024.04 单选9：= 必须成员函数重载）。
- `=` 和 `&` 系统**默认提供**重载版本（2025.04 填空26）。

#### 26.2 必背（成员 vs 友元参数个数）

| 重载方式 | 一元（++、!） | 二元（+、-、*） |
|---|---|---|
| 成员函数 | 0 个参数 | **1 个**参数（2025.10 单选8） |
| 友元/非成员 | 1 个参数 | **2 个**参数（2023.10 填空29） |

- 无参运算符函数 = **一元成员运算符**（2024.04 单选8）。
- `++a` 成员重载被编译器解释为 `a.operator++()`（2024.10 单选8）。

#### 26.3 易错点

```err
"运算符重载不能重载为全局函数"是错误说法——除 =[]()-> 外都可以重载为友元/全局函数（2023.04 单选7）。
```

```err
"调用运算符函数必须使用关键字 operator"是错误说法——运算时编译器自动调用，不用写 operator（2023.10 单选9）。
```

### 考点35：多重继承与二义性

meta: level=B; freq=2025.10、2024.04

#### 35.1 必背

```f

```

- 两个基类有**同名成员**时产生**二义性**：必须用 `基类名::成员` 限定访问。

### 考点38：多态的概念与联编分类

meta: level=B; freq=2023.10、2024.04、2025.04、2026.04

#### 38.1 必背

- 多态：**不同对象调用相同名称的函数**，产生不同行为（2024.04 单选13）。

### 考点39：虚函数与动态绑定

meta: level=S; freq=2023.04~2026.04 全部 7 套

#### 39.1 必背（动态绑定两条件 + 虚函数特性）

- 动态绑定两条件：① 函数声明为 **virtual** ② 通过**基类指针或引用**调用（2023.04 单选13、2025.04 单选15：基类对象指针）。
- 虚函数具有**继承性**：基类声明 virtual，派生类同签名函数自动成为虚函数（2025.10 单选12）。
- **静态成员函数、友元函数不能是虚函数**；构造函数不能虚、operator= 不要虚。
- 虚函数一般**不声明为内联**；类外定义时**不重复写 virtual**。
- 重写（覆盖）要求**函数名、参数表、返回值完全相同**；全局函数无多态。
- 在**构造函数和析构函数中不要调用虚函数**——此时对象不完整，不会发生动态绑定（大纲"领会"要求）。

#### 39.2 必背（声明格式）

```f
virtual 返回类型 函数名(参数表);     // 类内声明处写 virtual

```


### 考点44：标志字与 setf/setiosflags

meta: level=A; freq=2023.04、2023.10、2024.10、2025.04、2025.10

#### 44.1 必背（两种设置方式）

```f
cout.setf(ios::hex, ios::basefield);   // 成员函数：设置新进制前清互斥域（2023.10 单选17）
cout.setf(ios::scientific);
cout << setiosflags(ios::left) << ...;   // 操纵符版
cout << resetiosflags(ios::left);        // 清除标志
```

- **三大互斥域**：**basefield（dec|oct|hex）、adjustfield（left|right|internal）、floatfield（scientific|fixed）**。
- **标志字是什么**：每个流对象内部有一组格式开关位，`ios::xxx` 就是这些开关的常量名——`ios::dec` 十进制、`ios::oct` 八进制、`ios::hex` 十六进制、`ios::left/right` 对齐、`ios::scientific` 科学计数法……而 **`ios::basefield` 不是开关，是「域掩码」**：它等于 dec|oct|hex 三个开关的合并，用来一次性圈住整个进制域；同理 adjustfield 圈对齐域、floatfield 圈浮点域。
- **setf 两参数形式 `setf(新标志, 域掩码)` 的意思**：先把域掩码圈住的旧开关**全部清零**，再打开新开关——保证同域互斥的标志只剩一个。`cout.setf(ios::dec, ios::basefield)` 读作「进制域清零后设为十进制」，`setf(ios::hex, ios::basefield)` 就是「清掉 dec/oct 残留、切到十六进制」（2023.10 单选17）。**单参数 `setf(标志)` 只置 1 不清 0**，同域旧标志还挂着，dec|hex 同置后进制不可靠——所以进制/对齐/浮点域切换必须用两参数形式。
- 2023.04 分析45 首句 `cout.setf(ios::dec,ios::basefield)`：默认本来就是十进制，这句是「保险动作」，输出仍是 234，认识写法即可。
- 常见标志字：skipws、dec/oct/hex、showbase、showpoint、uppercase、showpos、scientific、fixed、unitbuf。
- setiosflags/resetiosflags 作用**持久**；setw/width **一次有效**（教材表 7-6 口径）。
- `setiosflags(ios::resetiosflags)` 是错误用法——resetiosflags 是独立操纵符不是标志字（2025.10 单选16）；教材习题答案中 `setiosflags(ios::hex)` 是合法用法。

| ios::app | **追加**（2025.04 单选18） | 总写到末尾 |
| ios::ate | 打开后定位到末尾 | 可移动 |
| ios::trunc | 截断清空 | |
| ios::binary | 二进制方式 | 组合用 \| 连接：ios::out\|ios::binary |

- 两种打开方式：`ifstream infile("D:\\f1.txt", ios::in);` 或先定义再 `infile.open("data.dat");`（2023.10 单选19、2023.04 填空33）。
- 读方式打开 → ifstream + ios::in；**二进制写** → ios::out|ios::binary（2024.04 单选18）。
- 判断打开失败：`if(!infile) {...}` 或 `if(infile.fail())`。
- **close()**：把缓冲区数据**写入文件**、加文件结束标记、断开连接（2025.04 填空30）。

### 考点48：文本文件读写

meta: level=A; freq=2023.04、2023.10、2024.10、2025.04、2025.10（2024.04 设计47 复核改判：写入/读出是成员函数非文件操作，归考点14；2026.04 缺席——5/7 套）

#### 48.1 必背（读写方式）

```f
ofstream fout("b.txt");            // 写文本
fout << name << " " << score << endl;
ifstream fin("a.txt");             // 读文本
fin >> a >> b;                     // 按空白分隔提取
while (fin >> a >> b) { ... }      // 按数据项读到 EOF（条件用读取表达式）
while (fin.getline(buf,80)) {...}  // 逐行读到 EOF
fin.get(ch);  fout.put(ch);        // 逐字符
```

- 文本文件是**无结构字节流**，Windows 下文本方式读写会做 `\r\n` ↔ `\n` 转换。
- 逐行读用 `fin.getline(buf, n)`；按数据项读用 `fin >> x`；循环条件**直接用读取表达式** `while (fin >> a >> b)` 或 `while (fin.getline(buf,n))`，不要用 `!fin.eof()`。
- 读一行加行号写出（2023.04 设计46）、读成绩排序写回（2024.10 设计41）都走这条路径。
- **逐行加行号写出模板**（2023.04 设计46，已编译实测）：`char buf[80]; int line = 0; while (fin.getline(buf, 80)) { line++; fout << line << ": " << buf << endl; }`——getline(buf, n) 第二参是最多读入的字符数（n−1 个 + 自动补 `\0`），遇 `\n` 停止并**把换行符从流中取走丢弃**，buf 里就是纯行内容；`>>` 按空白分隔提取，会把一行代码按空格切碎、丢掉缩进，做不了整行处理；当前文件夹下的文件直接写文件名，不用带路径。

```err
「读到哪里结束」的判断是考点48 最容易错的地方：while (fin >> x) 的读取表达式本身作条件，读成功为真、读失败（到文件尾）为假，循环自然结束。改成 while(!fin.eof()) { fin >> a >> b; 输出; } 一定多输出一遍最后一条记录——eof 是"上一次读取失败之后"才置位的标志，读完最后一条时它还是 false，循环会再进一次，这次读取失败但变量里仍留着上一条的值（sentry 失败时操作数不被修改），于是最后一条记录输出两遍。逗号误写 while (fin >> a, b, c) 只把最后一个操作数当条件，前面的读取被丢弃，常导致死循环；字段顺序也要和文件中的列一一对应，写反了整行串位。
```

## 考前速记

- 题型：2023–2025 口径 = 单选 20 + 填空 0~10 + 程序填空 20~30 + 程序分析 30 + 程序设计 20；2026.04 改版 = 单选 10×2 + 填空 5×2 + 程序填空 5 空×4 + 程序阅读 4×5 + 程序设计 2×15（是否延续【待核实】）。

- 标识符：字母/数字/下划线组成、不能数字开头、不能是关键字、区分大小写。
- 引用：必须初始化、是别名、不能换绑定、不能为空。

- setw 一次有效；setprecision 默认有效位；fixed/scientific 后变小数位。
- 互斥域：basefield / adjustfield / floatfield，切换前先清。
- class 默认 private 继承；protected=外界不可、派生类可。
- 构造顺序：基类→成员对象→自身；析构相反；虚基类一次。
- 复制构造三时机：初始化对象、传值实参、返回对象。
- 常对象只能调常成员函数；const 版本与非 const 版本构成重载。
- 静态成员：类外定义不写 static；静态函数无 this。
- 友元：单向、不传递、可访问私有。
- cerr 非缓冲、clog 缓冲，都不能重定向。
- 流状态：goodbit 0 / eofbit 1 / failbit 2 / badbit 4；Ctrl+Z 结束 cin。
- 文件模式：in（不存在出错）/ out（清空）/ app（追加）/ binary；二进制写= out|binary。
- 函数匹配顺序：普通函数 → 模板函数 → 转换后普通函数 → 报错。
- 类模板实例化：模板类→对象，必须给类型实参。
- 空类大小 1 字节；成员按最宽类型补齐。
